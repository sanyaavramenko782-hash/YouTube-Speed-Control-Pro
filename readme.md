# YouTube Speed Control Pro

Простое и легкое расширение для браузеров на базе Chromium (Google Chrome, Microsoft Edge, Brave, Opera), которое позволяет управлять скоростью воспроизведения видео на YouTube вплоть до **10x** с помощью удобной плавающей панели.

## Возможности

* **Ускорение до 10x:** Обходит стандартное ограничение плеера YouTube (2x).

* **Удобный ползунок:** Плавная регулировка скорости от `0.25x` до `10x` с шагом `0.25`.

* **Точный ручной ввод:** Поле для ввода любого точного значения (например, `1.5`, `3.2`, `7.5`) в диапазоне от `0.1` до `10`.

* **Минималистичный дизайн:** Полупрозрачная панель в левом верхнем углу плеера, которая не мешает просмотру.

* **Автоматическая синхронизация:** Корректно работает при переходе между видео без перезагрузки страницы.

## Установка

Поскольку это пользовательское расширение, оно устанавливается в режиме разработчика:

1. Создайте на компьютере новую папку (например, `youtube-speed-control`).

2. Поместите в эту папку два файла расширения:

   * `manifest.json`

   * `content.js`

3. Откройте браузер и перейдите на страницу управления расширениями:

   * Для **Chrome**: введите в адресную строку `chrome://extensions/`

   * Для **Edge**: введите `edge://extensions/`

   * Для **Brave**: введите `brave://extensions/`

4. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).

5. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) в левом верхнем углу.

6. Выберите созданную папку `youtube-speed-control`.

## Использование

1. Откройте любое видео на YouTube.

2. В левом верхнем углу видеоплеера появится панель управления с надписью **«Скорость:»**.

3. Передвигайте ползунок или впишите нужное число в поле ввода и нажмите `Enter` (или кликните вне поля), чтобы применить новую скорость.

## Примечания

* **Ограничения браузера:** На скоростях выше `4x–5x` браузер может автоматически отключать звуковую дорожку — это стандартное поведение движка Chromium для предотвращения искажений звука.

* **Безопасность:** Расширение работает исключительно локально в вашем браузере, не собирает никаких данных и не требует доступа к вашим аккаунтам.
